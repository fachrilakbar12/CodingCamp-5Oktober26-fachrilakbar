# Life Dashboard: project constraints

## Technical constraints
- HTML, CSS, and vanilla JavaScript only (no frameworks).
- No backend. Data is stored in the browser Local Storage.
- Must work in modern browsers (Chrome, Firefox, Edge, Safari).

## Folder rules
- Only 1 CSS file inside css/
- Only 1 JavaScript file inside js/
- Keep code clean and readable.

## Required features
- Greeting with time, date, and time-of-day message
- 25-minute focus timer with start, stop, reset
- To-do list: add, edit, mark done, delete (Local Storage)
- Quick links saved in Local Storage

## Chosen challenges
- Light / dark mode
- Custom name in greeting
- Prevent duplicate tasks
