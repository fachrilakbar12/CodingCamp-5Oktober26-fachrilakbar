# Life Dashboard

A simple dashboard that helps organize your day: current time and greeting, a 25-minute focus timer, a task list, and quick links. Built with HTML, CSS, and vanilla JavaScript. Data is saved in your browser's Local Storage.

## Features
- Live clock, date, and a greeting that changes through the day
- Focus timer (25 minutes) with Start, Stop, and Reset
- Tasks: add, edit, mark as done, delete
- Quick links: add and remove your own shortcuts

## Challenges included
- Light / dark mode (remembers your choice)
- Custom name in the greeting
- Duplicate tasks are blocked (case-insensitive)

## Run it
Open `index.html` in a browser. No install or build step.
